# 🛒 E-Commerce Website – ASP.NET MVC  

This is a fully functional **E-Commerce Website** built using **ASP.NET MVC** with a modern and responsive design. The project was developed over **35 days**, integrating various technologies to provide a seamless shopping experience.  

## 🚀 Key Features  

✅ **User Authentication & Authorization** – Secure login and registration using **ASP.NET Identity**  
✅ **Product Management** – CRUD operations for adding, editing, and deleting products  
✅ **Shopping Cart & Checkout** – AJAX-based cart for a smooth user experience  
✅ **Secure Payment Integration** – **Stripe** payment gateway for processing transactions  
✅ **AJAX & jQuery** – Used for dynamic updates and interactive elements  
✅ **Bootstrap & CSS** – Responsive and mobile-friendly UI design  
✅ **Admin Panel** – Manage products, users, orders, and more  
✅ **Performance Optimizations** – Efficient database queries and caching  

## 🛠 Technologies Used  

- **Backend:** ASP.NET MVC (C#)  
- **Frontend:** HTML, CSS, Bootstrap  
- **Scripting & Dynamic Content:** JavaScript, jQuery, AJAX  
- **Payment Gateway:** Stripe API  
- **Database:** Entity Framework with SQL Server  
- **Architecture:** Dependency Injection (DI) for better maintainability and scalability
